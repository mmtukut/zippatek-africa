# **App Name**: Zippatek Africa

## Core Features:

- AI Property Verification: Uses AI and satellite data as a tool to automatically verify property details, flagging potentially fraudulent listings.
- Propabridge Marketplace: AI-powered marketplace connecting renters and buyers with verified landlords and developers, enhancing search using machine learning for user preferencing
- FastFind360 Satellite Mapping: Allows local and federal goverments, or enterprise partners to uncover hidden assets and unlock bilions in tax revenue. This proprietary product displays it using heat maps, property overlays, or interactive property layers.
- Dynamic Property Search: Provides AI-enhanced dynamic search parameters using predictive reasoning to optimize user queries, increasing the performance and scope of property results.
- Interactive Map Integration: Utilizes interactive maps to display property locations and insights from satellites, designed with custom markers, customizable layers and a focus on mobile device access.
- Revenue Intelligence Dashboards: Develops enterprise dashboards showcasing key performance indicators (KPIs), such as total properties mapped and potential tax revenue uncovered.
- AI Customer Support Chatbot: Implements a support chatbot powered by generative AI, for seamless user support. The tool has access to the customer account and purchase history, can answer questions, provide information, and navigate user requests

## Style Guidelines:

- Primary color: Deep blue (#1E40AF) representing trust and stability, creating a corporate feel for the PropTech brand.
- Background color: Very light blue (#F3F4F6) maintaining a clean and modern look.
- Accent color: Electric cyan (#06B6D4) symbolizing speed and cutting-edge innovation to make data visualizations more appealing.
- Body font: 'Inter' (sans-serif) ensuring readability and a modern look throughout the site. Headings 'Space Grotesk' to maintain uniformity.
- Custom Icons in Airbnb rounded style should follow Zippatek's design which include map pins, charts, data streams.
- Cards utilize glass morphism and Airbnb's rounded design to enhance UX. Every element from listing blocks to CTA will follow rounded philosophy and follow material UIs to increase native UX on every app platform.
- Motion blur when cards open from a listing, interactive loading bars and subtle satellite animations to ensure UX on every website aspect.
